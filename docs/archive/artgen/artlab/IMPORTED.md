# artlab (imported reference)

The procedural sprite experiment harness behind `FINDINGS.md` and `FINDINGS-iso.md`, imported unchanged as the
reference and benchmark source for artgen (see `../DECISIONS.md` D11). Only the two final comparison sheets are
kept from `out/`; `node run.js all` regenerates the rest.

Not part of the app build or tests. Run it from this folder: `npm install && node run.js report`.
Kept until artgen fully supersedes it (PLAN P8), then archived with the planning docs.
