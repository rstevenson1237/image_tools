# T2+ reference (S1 base + S2 procedural pass)

```js
// art/assets/character/goblin/base.v2.js — header: what changed vs v1
export const meta = { brief: 'goblin', pass: 'r2', notes: 'longer ears, rusty cleaver' };
export const params = {                                     // optional schema → seeded variants (artgen variants)
  cloth: { type: 'swap', options: ['cloth', 'leather'], default: 'cloth' },
  hood: { type: 'toggle', default: false, p: 0.3 },
  ears: { type: 'range', min: 2, max: 4, step: 1, default: 3 },
  weapon: { type: 'choice', options: ['cleaver', 'club'], default: 'cleaver' },
};
export function render(ctx) {
  const { pal } = ctx.dir, P = ctx.params, [w, h] = ctx.size, s = ctx.lib.t2.scene(w, h);
  s.add({ type: 'path', name: 'body', d: 'M8 12 H16 L17 20 H7 Z', mat: pal[P.cloth], shade: 'normal', round: 3, underlay: true });
  s.add({ type: 'rect', name: 'eye', x: 10, y: 7, w: 1, h: 1, color: 'accent.0', mirrorX: w / 2 });
  return ctx.lib.proc(s).add('materialNoise', { part: 'body', amount: 0.2 }).add('groundShadow', {}).render();
}
export const anchors = ctx => ({ head: [12, 6] });          // named points per frame, used by finishing patches
```

`ctx`: `dir` (direction + `pal` ramps lightest-first, `outline`, `shadow`), `brief`, `size` [w,h], `seed`, `variant`,
`params`, `state`, `facing`, `frame`, `t` (frame/frames), `rng()`, `lib`, `palette(names?)`, `stage(name, grid)`.

## Shapes (pixel coordinates, SVG semantics)
`rect` (x y w h, `r` corner radius) · `ellipse` (cx cy rx ry) · `circle` (cx cy r) · `poly` (pts) · `path` (SVG `d`) ·
`line` (x0 y0 x1 y1 w) · `capsule` (a b r, `r1` tapers) · `tube` (band along `d`/`pts`, `w` → `w1`) · `ring` (cx cy r w) ·
`arc` (cx cy r w a0 a1) · `star` (cx cy r r2 n rot) · `union` / `subtract` / `intersect` over `shapes`.

## Nodes and groups
`translate [x,y]`, `rotate` (deg), `scale`, `origin`, `flip`, `z` (order), `mirrorX`/`mirrorY` (adds a mirrored copy
shaded for its own side). Groups: `children`, `clip` (a shape), `repeat: { n, dx, dy, rotate, origin }`; `mat` and
`shade` inherit.

## Style
- `mat`: ramp array, ramp name, or material name (`'metal'`, `'wood'`); `color`: token (`'outline'`, `'accent.0'`) — no shading.
- `shade`: `flat` (+ `band` index), `bevel`, `sphere`, `cyl` (+ `axis: 'x'|'y'`), `normal` (+ `round` px), `linear`; `gain`.
- `underlay: true` (dark copy beneath that inks only over content below it), `ink` / `ink: 'all'`, `cast` (px), `ao`, `name`.
- Scene options: `ctx.lib.t2.scene(w, h, { mode: 'direct'|'ss', ss, outline: false, shadow: [dx,dy], groundShadow: [cx,cy,rx] })`.
  `direct` (coverage threshold) up to `pipeline.raster.directMaxPx`, `ss` supersampling above it (R3).

## 3D mode (iso props, rotations, states)
```js
const m = ctx.lib.t2.scene3d();                               // set meta.mirror = false: every facing comes from the model
m.add({ type: 'box', name: 'body', x: 0, y: 0, z: 0, w: 6, d: 4, h: 3, mat: 'wood' });
m.add({ type: 'slab', name: 'strap', x: 1, y: 0, z: 0, w: 1, d: 4, h: 4, mat: 'metal' });   // recolours the surface (R5)
return m.render(w, h, { ox: 16, oy: 18, facing: ctx.facing });   // 1 unit = 2 px across, 1 px down; s/w/n/e facings
```
Also `ellipsoid`, `capsule`, `sdf` (fn + bbox), `group` (translate, rotate in 90° steps, mirror), booleans; `hi: 'glow.0'`
edge highlight; `slab` with `add: true` fills empty cells (raised trim).

## Procedural pass (S2)
`ctx.lib.proc(sceneOrGrid).add(layer, { part, mat, ... }).render()` — layers: `materialNoise` (amount, scale, octaves),
`pattern` (type stripes|planks|bricks|grid|checker|rivets, period, axis, width, length, step), `rimLight` (side),
`ao`, `castShadow` (dist), `dither` (only if the direction allows), `groundShadow` (cx, cy, rx or auto), `dropShadow`.
The direction's `pipeline.procedural` adds default layers; `.noDefaults()` skips them (tiles, effects).

## Lint (fails the gate)
Strokes (R4), colours outside the asset palette (R11), hex literals in source (R11). Flagged: interpenetrating 3D
solids (R5), shapes that cover no pixels.
